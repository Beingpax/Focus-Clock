# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Delegated: lightweight static HTML, CSS, and JavaScript for easy local use and hosting.

## Users

People who want a quiet, time-aware music experience running in a browser.

## Product Purpose

Turn a supplied YouTube playlist into a calm sunset radio with a tactile three-mode flip clock.

## Positioning

The interface behaves like a place and a radio, not a general-purpose playlist manager.

## Operating Context

Desktop or mobile browser, typically left open while listening. The first interaction starts playback because browsers restrict audible autoplay.

## Capabilities and Constraints

- Uses the YouTube IFrame Player API behind an original custom audio-style control surface for private local use.
- Uses a selected static mountain photograph and a CSS 3D split-flap Clock, Stopwatch, and Timer.
- The circular mode wheel supports click, mouse wheel, trackpad, touch/pointer drag with projected release velocity, and arrow-key selection.
- Timer mode adds a matching duration wheel on the opposite side of the enlarged central display.
- Avoids WebGL, video decoding, and continuous visual animation.
- Does not host, extract, cache, or restream music.

## Brand Commitments

Quiet golden-hour atmosphere; restrained, usable controls; lightweight original visuals.

## Product Principles

- The environment leads and the interface recedes.
- Playback remains understandable and controllable through familiar music controls.
- Load only the runtime resources needed for the current experience.
- Remain usable with reduced motion, reduced data, or without WebGL.

## Accessibility & Inclusion

Keyboard-visible controls, readable contrast, responsive layout, and reduced-motion support.
